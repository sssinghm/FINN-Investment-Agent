# Research document index

`index.json` contains a small, curated reference excerpt from TCS's official Integrated Annual Report 2025–26 performance-trend table. It is included only to demonstrate retrieval, citations, financial trend calculations and the research UI immediately after startup. It is not a complete report extraction. The primary PDF URL is included in its metadata.

Other companies have no indexed primary documents by default. Use `scripts/ingest_document.py` with company/exchange primary-source URLs to extend the library. Review extracted text, financial scope and units before treating it as evidence.
